Set up in under a minute

  1. Plug it in

    Set it on open floor with the lens facing the room. Run the USB cable to a wall adapter.

  2. Tap the top button

    The holes light up and the first mouse peeks out. Tap again to switch it off.

  3. Dim the lights

    The mice glow brightest in a dark room. Your cat takes it from there.

Questions

Is it a laser?

No. It projects LED light patterns, so there is no laser beam. Still, don't point the lens at anyone's eyes.

Does it need batteries?

No. It runs from a USB cable plugged into a wall adapter, so there is nothing to charge.

Does it work with the lights on?

It works best in a dim room. In bright daylight the mice are faint, so evening is the best time to play.

Will my cat play with it?

Most cats chase moving light, but every cat is different. Start when your cat is awake and curious, and give it a few sessions.
